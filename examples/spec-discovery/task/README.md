# 방문 접수 창구 운영 검토 — 합성 연습 과제

이 문서와 데이터는 FDE Kit 검증을 위해 만든 허구의 연습 자료입니다. 실제 대회 문제, 현장 기록이나 채점표가 아닙니다.

## 목적

접수 창구 담당자가 현재 자료의 처리 여력과 운영상 주의할 상황을 이해하도록 도와주세요. 어떤 운영 대응이 적합한지는 제공된 담당자 AI에게 업무 맥락을 확인하고 참가자가 선택합니다. 담당자에게 질문할 수 있습니다.

## 제공 입력

`arrivals.csv`의 한 행은 특정 날짜의 한 시간 구간에 집계한 접수 건수입니다. `hour`는 Asia/Seoul 기준 구간 시작 시각이며, 10은 10:00 이상 11:00 미만입니다. `capacity`는 해당 구간의 처리 가능 건수입니다. 행에 없는 시간대나 날짜의 값은 제공하지 않습니다. 자료가 전체 업무를 대표하는지는 이 README만으로 알 수 없습니다.

## 필수 산출물

- R1: `out/coverage.csv`. 입력의 각 행을 빠짐없이 한 번씩 출력하며 열은 `date,hour,arrivals,capacity,gap` 순서입니다. `gap = max(arrivals - capacity, 0)`입니다. 날짜, 시간 오름차순으로 정렬합니다. 행이 없는 구간을 0건으로 채우지 않습니다.
- R2: `out/plan.md`. 데이터에서 확인한 사실과 한계, 담당자가 알려준 업무 맥락, 선택한 운영 대응과 근거를 구분해 설명합니다. 자료에 없는 수요량이나 인원 수는 만들지 않습니다.
- R3: 실행 코드와 검사 방법을 제출하고, 기존 과제 문서에 실행 방법을 남깁니다. Python 기본 라이브러리만 사용합니다. 네트워크 서비스나 실제 인력 배치를 실행하지 않습니다.

## 현재 단계

지금은 README와 데이터를 읽어 구현 명세를 작성하는 단계입니다. 아직 구현하지 않습니다. 화면은 요구하지 않습니다. 실제 담당자에게 보낼 질문은 참가자가 전달하며, 답변을 받기 전까지 운영 규칙은 미정으로 둡니다. 내부 구현은 결과와 위 제약을 보존하는 범위에서 에이전트가 정할 수 있습니다.
