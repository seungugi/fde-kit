# 상황별 복사용 프롬프트

처음 만든 두 프롬프트는 문제 정의를 시작하기에 충분하다. 이후 구현을 맡기거나 검증·인계를 요청할 때는 목적에 맞는 짧은 프롬프트를 골라 쓰면 된다. 이 목록 전체를 순서대로 실행할 필요는 없다.

아래 파일의 필요한 코드 블록 하나만 복사한다. `[대괄호]`는 알려진 내용으로 바꾸고, 모르는 내용은 미확인이라고 적는다. 프롬프트 파일은 자동 실행되는 스킬이 아니며 모델의 정확성을 보증하지 않는다.

| 대화 상대 | 파일 | 역할 |
|---|---|---|
| Codex | [codex.md](codex.md) | 문제 정리, 다음 질문 선택, 구현·분석, 검증, 인계 |
| 업무 담당자 AI | [stakeholder.md](stakeholder.md) | 실제 업무 사례, 판단 기준, 기대 결과와 운영 조건 확인 |

## 보통 이렇게 사용한다

1. Codex에 **C1 문제 정의 시작**과 과제 원문을 보낸다. 업무 담당자 AI와의 첫 대화는 **S1 최근 사례**로 시작한다.
2. 담당자 답을 Codex에 **C2 답변 반영**으로 전달한다. 이후에는 Codex가 골라준 다음 질문 하나만 담당자에게 보낸다. 이미 답이 충분하면 추가 인터뷰를 생략한다.
3. 해결 범위를 정했으면 **C3 범위 확정·실행**을 쓴다. 범위를 아직 정하지 못했다면 먼저 담당자와 **S4 합의 확인**을 한다.
4. 결과가 나오면 **C4 검증·약점 확인**을 쓴다. 현재 근거로 이미 충분한 검사를 반복할 필요는 없다. 검증과 handoff를 함께 마쳤다면 종료 때 C7을 다시 보낼 필요도 없다.

짧은 시작 프롬프트 이후에는 평소 말로 이어가도 된다. 매번 긴 프롬프트나 `$fde-kit`를 반복해서 붙일 필요는 없다.

Codex가 저장소 파일에 접근할 수 있으면 “키트 저장소의 prompts/codex.md에서 C3를 읽고, 아래 확정 범위에 적용해줘”처럼 특정 항목만 지정해도 된다. 파일이 어디 있는지 모르는 세션에는 실제 저장 위치를 함께 알려준다. `init`은 스킬을 설치하며 저장소 최상위의 이 prompts 폴더를 과제 폴더에 자동 복사하지는 않는다.

## 상황별 찾기

| 상황 | 보낼 곳 | 선택 |
|---|---|---|
| 처음 문제를 이해할 때 | Codex / 담당자 | C1 / S1 |
| 담당자 답이 추가되거나 조건이 바뀜 | Codex | C2 |
| 결과물을 받아 무엇을 할지 불명확함 | 담당자 | S2 |
| 판단 규칙이나 예외의 정답이 불명확함 | 담당자 | S3 |
| 구현 전 최소 범위를 맞춰봄 | 담당자 / Codex | S4 / C3 |
| 같은 용어·조건을 서로 다르게 말함 | 담당자 | S5 |
| 결과를 누가 갱신·운영할지 불명확함 | 담당자 | S6 |
| 결과의 정확성이나 약점 확인 | Codex | C4 |
| 오류가 나서 원인 파악·수정 필요 | Codex | C5 |
| 마감 전에 범위를 조정해야 함 | Codex | C6 |
| 세션을 마치거나 넘김 | Codex | C7 |
| 새 세션에서 이어감 | Codex | C8 |
| AI 사용이 허용된 단계에서 설명 연습 | Codex | C9 |

## 적용 범위

- Codex용은 과제 폴더에 fde-kit가 설치되어 있음을 전제로 한다. 설치는 [저장소 README](../README.md), 짧은 작업 흐름은 [execute](../skills/fde-kit/references/execute.md#small-single-owner-work)를 참고한다. 이미 Codex 대화 안이면 `launch`를 중첩 실행하지 않는다.
- 담당자용은 이미 제공된 업무 담당자 AI와 대화하기 위한 문장이다. 상대의 역할·설정·권한을 바꾸거나 없는 사실을 만들어 달라는 역할극 프롬프트가 아니다. 답변도 실제 자료와 대조할 근거이지 무조건 사실로 확정할 정보는 아니다.
- 공개 저장소에는 이 일반 양식만 둔다. 실제 과제 원문·담당자 답변·회사 자료·키·작업 로그를 채운 버전은 과제 환경에 보관하며 공개 저장소로 올리지 않는다. 대회에서는 제공 환경의 허용된 인터페이스 안에서만 대화 내용을 옮긴다.
- 대회에서는 실제 안내와 [competition 제한](../skills/fde-kit/references/profiles.md#competition-restrictions)이 우선한다. 이 키트의 하이닉스 대회 프로필은 Computer Use 전 단계 금지와 Astra 사용 제한을 명시한다. 참가자가 화면을 직접 조작하며 Codex에 금지된 조작의 자동화를 요청하지 않는다.
- C9는 AI 사용이 허용된 준비·작업 단계용이다. AI 사용이 금지된 후속 서술형에서 답안 작성·첨삭·문제 풀이에 사용하지 않는다.

프롬프트는 일을 이해하고 요청 범위를 전달하는 도구다. 업무 규칙의 확인, 의미 있는 기대값, 실제 실행 결과를 대신하지 않는다.
