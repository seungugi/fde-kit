# 합성 예제: 요청 처리 정책

긴급 요청 처리 기준: 심각도 high이고 대기 시간이 24시간 이상이면 critical로 분류한다. 정확히 24시간도 포함한다.

심각도 high이면서 위 조건에 해당하지 않으면 urgent로 분류한다.

그 외 대기 시간이 24시간 이상이면 due로 분류한다.

나머지 유효 요청은 routine으로 분류한다. 같은 등급은 요청 ID 오름차순이다.

누락·음수 시간·알 수 없는 심각도·유효하지 않은 금액은 담당자 확인 대상으로 둔다. 금액 미입력은 집계 분모에서 제외하며 0원으로 단정하지 않는다.

분류 결과는 자동 실행 승인이 아니다. 실제 고객 연락과 상태 변경은 업무 책임자가 결정한다.
